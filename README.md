# Talent Hub

**Ուսանողների հմտությունների, առաջընթացի և մասնագիտական ներուժի բացահայտման ցուցադրական հարթակ։**

Talent Hub-ը ուսանողների ուսումնական ուղին, տեխնիկական հմտությունները, նախագծերը և մասնագիտական պատրաստվածությունը մեկ միջավայրում ներկայացնող վեբ հավելված է։ Այն նախատեսված է որպես ինքնուրույն արտադրանքի հայեցակարգ և ցուցադրական նախագիծ։

## Ինչով է առանձնանում

Սովորական ակադեմիական կայքերը հիմնականում ներկայացնում են դասընթացներն ու ուսումնական հաստատությունը։ Talent Hub-ը կենտրոնանում է նաև ուսանողների կարողությունների բացահայտման և ներկայացման վրա։ Դրա հիմնական առանձնահատուկ բաժիններն են՝

- **Talent Discovery** — ուսանողների որոնում ու համադրում՝ ըստ հմտությունների, դասընթացի, հմտության մակարդակի, առաջընթացի, նախագծերի և պորտֆոլիոյի ամբողջականության։ Կազմակերպության հյուրերը կարող են պահպանել հետաքրքիր պրոֆիլները տեղային ընտրվածների ցանկում։
- **Student Ranking** — ցուցադրում է ուսանողների առաջատար 15 դիրքերը և ուսանողի սեփական դիրքը։ Դեմո միավորները հաշվարկվում են ուսումնական ցուցանիշների, պորտֆոլիոյի և ուսուցչի դրական գնահատումների օրինակելի տվյալներով։

## Հիմնական հնարավորություններ

- Ուսանողների որոնելի ու զտելի տեղեկատու՝ քարտային և աղյուսակային դիտումներով։
- Ուսանողի մանրամասն պրոֆիլ՝ ուսումնական առաջընթացով, հմտություններով, նախագծերով, ձեռքբերումներով և ուսումնական ճանապարհային քարտեզով։
- Դասընթացների և ճանապարհային քարտեզների դիտում՝ փուլերով, մոդուլներով, թեմաներով ու օրինակելի առաջադրանքներով։
- Հմտությունների ուսումնասիրում և նախագծերի պատկերասրահ։
- Տաղանդների որոնում՝ նախապես պատրաստված օրինակելի հարցումներով և փոփոխվող զտիչներով։
- Վերլուծական վահանակներ, որոնց ցուցանիշները հաշվարկվում են նույն դեմո տվյալներից։
- Երեք դիտման ռեժիմ՝ **Admin**, **Student** և **Guest Viewer**։ Ուսանողի ու հյուրի ռեժիմները դիտման համար են. տվյալների խմբագրման գործիքները հասանելի են միայն ադմինին։
- Անգլերեն և հայերեն ինտերֆեյս, բաց և մուգ թեմաներ, հարմարեցվող աշխատասեղանի ու բջջային դասավորություն։
- Փոփոխությունների պահպանում զննարկչի `localStorage`-ում և սկզբնական դեմո տվյալները վերականգնելու հնարավորություն։

## Դեմո տվյալների և գնահատումների մասին

Բոլոր ուսանողների անունները, լուսանկարները, հմտությունները, նախագծերը, գնահատականները և վիճակագրությունը հորինված են։ Talent Hub-ը անկախ ցուցադրական նախագիծ է․ այն պաշտոնական ուսումնական հարթակ չէ։ Վարկանիշը, համապատասխանության միավորը և պատրաստվածության ցուցիչները միայն արտադրանքի ցուցադրման համար են. դրանք պաշտոնական գնահատումներ կամ աշխատանքի ընդունման առաջարկներ չեն։

Հյուրի ընտրվածների ցանկը պահպանվում է տվյալ զննարկչում և չի ուղարկվում սերվեր։ Նախագծում նույնականացում կամ իրական կազմակերպությունների հետ կապ հաստատելու գործառույթ չկա։

## Տեխնոլոգիաներ

- React և TypeScript
- Vite
- React Router
- Recharts
- Lucide React
- CSS դիզայն համակարգ և `localStorage`

## Գործարկում

Պահանջվում է Node.js և npm։ Ծրագրի թղթապանակում կատարեք՝

```bash
npm install
npm run dev
```

Ստուգումների և production build-ի համար՝

```bash
npm run check
npm run build
```

## Նախագծի կառուցվածքը

```text
src/
  App.tsx                 Էջեր, նավիգացիա և դիտման ռեժիմներ
  components/Ranking.tsx  Ուսանողների վարկանիշ և ակադեմիական ցուցանիշներ
  data/seed.ts            Կենտրոնացված հորինված ուսանողների ու նախագծերի տվյալներ
  lib/ranking.ts          Վարկանիշի հաշվարկման տրամաբանություն
  types.ts                TypeScript տվյալների տեսակներ
  i18n.ts                 Հայերեն և անգլերեն թարգմանություններ
  styles.css              Տեսողական ոճեր և հարմարեցվող դասավորություն
demo-video/               Հայերեն ցուցադրական տեսանյութ, ենթագրեր և նկարներ
```
